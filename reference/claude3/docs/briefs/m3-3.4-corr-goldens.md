# Brief M3 3.4: correlation goldens via an explicit --update-golden mode

Tester task. Not tracked. Rules: `.claude/rules/project.md` ("Record golden results as JSON
under tests/golden/; regenerate only with an explicit --update-golden flag and a commit
message explaining why"; ASCII; vocabulary gate; fixtures via MTC_TEST_DATA_DIR, skip when
absent; no absolute paths). Plan section 8 (tolerances). The edge regression suite
(`tests/regression/golden_regression_test.cpp`, `tests/test_support/golden_case.h`) is the
template; keep the existing edge suite and its 28 goldens byte-identical.

## Mechanism (reusable later for library-side goldens of other cases)

- The regression executable gets its own `main()` (replace `GTest::gtest_main` for that
  target only): it strips `--update-golden` from argv before `InitGoogleTest`, and sets a
  process-wide flag. Default runs never write files.
- Library goldens live under `tests/golden/library/<suite>/<case>.json` with their own schema
  (`"schema": "mtc-library-1"`, `"generator": "mtc"`, the inputs that produced them, and the
  object list: anchor, corners (corners()[1,2,3,0] = LT,RT,RB,LB), matchedAngle, score,
  patternIndex, verdict and reasons). Writing uses cv::FileStorage in MEMORY mode + binary
  ofstream (see `.claude/docs/notes/filestorage-findings.md`), sorted deterministically
  (score desc, then anchor y, x). Float output must round-trip: write doubles.
- `tests/golden/library/correlation_cases.json` lists the correlation cases: name, pattern,
  source (relative to the data dir), and the options (method, useMask, coarseAngleStep,
  fineAngleStep, minScore, toleranceAngle, maxOverlap, maxPosNum, subPixel), plus an optional
  skipReason.
- Update mode: runs every listed case, writes the JSON, and ALSO writes a preview PNG per case
  into a directory outside the tree given by `--preview-dir <path>` (default: none; required
  for the lead's review), drawing every object's rotated rect and anchor on the source.
- Normal mode: parameterized test over correlation_cases.json comparing a fresh run with the
  stored library golden at the tight tolerance (0.25 px, 0.1 deg, 0.005 score; nearest
  neighbour, unordered; counts must match exactly since both sides are the same library).
  Missing golden file -> GTEST_SKIP with "run with --update-golden".

## Case selection

Start from the fixtures whose EDGE goldens pass (cases.json without skipReason) and use the
same pattern/source pairs with CcoeffNormed defaults (useMask false, minScore from the edge
case). Add `useMask: true` variants for two cases with cluttered backgrounds if any (choose
from the previews). Do NOT add the 6 skipped src5 cases (pending a user decision). Measure the
time per case in Release; drop (with skipReason "too slow for the unit suite: N ms") any case
over 5 s in Release.
