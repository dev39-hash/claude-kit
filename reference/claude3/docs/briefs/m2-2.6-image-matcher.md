## Public API

```cpp
// include/mtc/search_options.h
namespace mtc {
/// Per-call options of ImageMatcher::match().
struct SearchOptions {
    bool usingRoi = false;        ///< Restrict the search to @c roi.
    cv::Rect roi;                 ///< Region of interest in the source image (when usingRoi).
    int stopAfterOkCount = 0;     ///< Stop after this many Ok objects (0 = no limit). The stop is
                                  ///< evaluated between candidate regions, so the result may
                                  ///< hold more objects than the count.
    bool annotate = false;        ///< Also produce MatchResult::annotated.
};
}

// include/mtc/matching_types.h (addition; also extend matchStatusName())
MatchStatus::NotReady,  ///< prepare() failed (invalid group config, unsupported condition,
                        ///< or a matching type without a strategy); see ImageMatcher::prepare().

// include/mtc/image_matcher.h
namespace mtc {
class ImageMatcher;   // not MTC_API as a class (STL / unique_ptr members); members exported
/// Facade: owns a MatchGroup, runs the pipeline of plan section 4. Not thread-safe: one
/// instance per worker thread, built from a deepCopy() of the group.
class ImageMatcher {
public:
    /// Takes ownership of @p group. @p logger is optional and non-owning.
    MTC_API explicit ImageMatcher(MatchGroup group, ILogger* logger = nullptr);
    MTC_API ~ImageMatcher();
    ImageMatcher(const ImageMatcher&) = delete;
    ImageMatcher& operator=(const ImageMatcher&) = delete;
    MTC_API ImageMatcher(ImageMatcher&&) noexcept;
    MTC_API ImageMatcher& operator=(ImageMatcher&&) noexcept;

    /// Read access to the group.
    MTC_API const MatchGroup& group() const noexcept;
    /// Write access; marks the matcher as needing prepare() (done lazily by match()).
    MTC_API MatchGroup& group() noexcept;
    /// Replaces the group (moved in); needs prepare().
    MTC_API void setGroup(MatchGroup group);

    /// Validates the group config, checks every condition against the matching type
    /// (IMatchCondition::requiresForeground() on a correlation group -> failure "unsupported
    /// condition"), selects the strategy (EdgeBased -> EdgeStrategy; any other type ->
    /// failure "no strategy for <type>" until M3), creates the workspace and installs the
    /// classifier. Cheap when nothing changed. @return ok or the first failure.
    MTC_API ManagerResult prepare();
    /// True after a successful prepare() and until the group is touched.
    MTC_API bool isReady() const noexcept;

    /// Learns every pattern of the group with the selected strategy (calls prepare() first).
    MTC_API ManagerResult learn();

    /// Runs one search. @p result is cleared (capacity kept) and filled; steady-state calls
    /// with the same image size allocate nothing in library code.
    /// @param[in] source CV_8UC1, CV_8UC3 or CV_8UC4 image; not modified, not retained.
    /// @param[in] options Per-call options.
    /// @param[out] result Result (objects in the ORIGINAL image frame).
    /// @return result.status (also stored in the result).
    MTC_API MatchStatus match(const cv::Mat& source, const SearchOptions& options,
                              MatchResult& result);
    /// Convenience overload returning a fresh result.
    MTC_API MatchResult match(const cv::Mat& source, const SearchOptions& options = {});

    /// Logger accessors (non-owning).
    MTC_API void setLogger(ILogger* logger) noexcept;
    MTC_API ILogger* logger() const noexcept;

private:
    struct Impl;                    // src/match/image_matcher_impl.h (workspace, strategy, ...)
    std::unique_ptr<Impl> m_impl;
};
}
```

`MatchedObject` keeps `patternIndex` only (no `patternName` string: no per-object string
allocation; hosts map the index through the group).

## Pipeline (match)

Status order: `EmptySource` (empty or non 8-bit 1/3/4-channel source) -> `NotReady` (prepare
failed) -> `NoPatterns` (group empty) -> `UnlearnedPattern` (any pattern not learned) ->
`InvalidRoi` (usingRoi and `roi & imageRect` empty). On any failure `result.status` is set,
objects empty, `result.region` = the region that would have been used (or empty) and the
function returns the status without searching.

1. **Gray**: convert the source into a workspace Mat (BGR2GRAY / BGRA2GRAY / copyTo for
   gray; `cv::Mat::create` reuse). `region` = clamped roi when usingRoi, else the full image.
   **Crop**: copy `gray(region)` into an owned workspace crop (standalone Mat, so every
   downstream filter uses isolated borders, as the reference's clone() did). Timing starts here
   (`std::chrono::steady_clock`); `stats.totalMs` at the end.
2. **Foreground** (edge mode only): `fg::ForegroundExtractor::extract(crop, fgResult)` with the
   group's ForegroundConfig (extractor kept in the Impl; setConfig on prepare);
   `stats.foregroundArea = totalArea`, `stats.foregroundMs`. Correlation mode: no foreground,
   `MatchContext::foreground = nullptr`. `stats.largestPatternArea` = max expectedArea().
3. **Candidate regions** (edge mode, reference rule): for every contour whose class is not
   Oversize: `area = int(contourArea)`; the pattern list = patterns p with
   `int(p.expectedArea() * 0.7) <= area <= int(p.expectedArea() * 4.3)` (ratios as named
   constexpr `kLowerAreaRatio = 1.0 - 0.3`, `kUpperAreaRatio = 4.0 + 0.3`); when non-empty
   the region is `boundingRect(contour)` grown by `kCropPad = 70` on each side and clamped to
   the crop (`geom::paddedRect`). Regions are processed in DESCENDING contour area (plan
   decision; ties by contour index). Correlation mode: one region = the whole crop with every
   pattern. `stats.candidateRegions` = number of regions.
4. **Search**: for each region, for each listed pattern: copy `crop(regionRect)` into an owned
   workspace sub-crop (standalone Mat; `ScratchImage` from src/core/scratch_image.h) and call
   `strategy.search(subCrop, *pattern.learned(), params, workspace, candidates)` with
   `SearchParams` built from the pattern config (minScore, toleranceAngle) and the type
   config (maxOverlap, maxPosNum, subPixel = subPixelEstimation, stopAtLayer1, maxMatches if
   the config has it; `stats`, `logger`). Candidates come back in sub-crop coordinates:
   translate center and rect.center by `regionRect.tl()`, set `patternIndex` to the pattern's
   position in the group. `stats.rawCandidates += candidates of this region`.
5. **Global overlap pass per region** across patterns (reference `FilterWithRotatedRect` on
   `m_final_overlap_result` with the matcher-level maxOverlap = type config maxOverlap):
   implement `match::filterOverlap` for `std::vector<Candidate>` with the same rule as the
   MatchParams overload (pairs i < j, containment deletes the lower score, else
   intersection area / area_i > maxOverlap deletes the lower score, ties delete j; order of
   survivors preserved); reuse `geom::intersectionArea` and the scratch vector. Place it in
   src/match/candidate_filter.{h,cpp} next to the existing overload.
6. **Objects**: for each surviving candidate build a `MatchedObject` in the CROP frame:
   `size = pattern size`, `setPose(center, angle, patternConfig.angleOffset)`,
   `anchor = MatchedObject::transformAnchor(patternConfig.anchorPoint, size, matchedAngle)`
   applied around `center` exactly as the existing MatchedObject API defines it (read
   include/mtc/matched_object.h and its test for the formula and call), `score`, `patternIndex`,
   `outcomes.clear()`. Then **phase 1** immediately: `Classifier::evaluateObject(obj, ctx)` with
   `ctx = {source = &crop, foreground = &fg.mask (edge) / nullptr, stats = &result.stats,
   region, found = &result.objects, patternConfig = &pattern.config(), patternFootprint =
   &pattern.footprintMask() (edge) / nullptr, logger}`; push into `result.objects`.
   After the region: if `options.stopAfterOkCount > 0` and the number of Ok objects so far
   >= stopAfterOkCount, stop processing further regions (documented: "first N Ok in
   candidate-region order"). `stats.searchMs` covers steps 3-6 without the conditions;
   `stats.conditionsMs` the condition calls (accumulate with the clock around them).
7. **Phase 2**: `Classifier::evaluateSet(result.objects, ctx)` (patternConfig and
   patternFootprint null). `Classifier::countVerdicts` -> okCount / ngCount.
8. **Sort** (`stats.sortMs`): Ok objects first, then by score descending, or when
   `groupConfig.sortByAngle` by the smallest wrapped |angle - sortTargetAngle|; deterministic
   total order (tie-break by center.y, center.x, patternIndex) with `std::sort` (no
   allocation); `src/match/result_sort.{h,cpp}`. Then truncate to `maxMatches` when the type
   config defines a positive one (document where it comes from).
9. **Image frame**: `obj.translate(region.tl())` for every object; `result.region = region`;
   `stats.matches = objects.size()`.
10. **Annotate** (`options.annotate`, `stats.annotateMs`): `result.annotated` = BGR copy of the
    full source (`cv::Mat::create` reuse; gray -> GRAY2BGR, BGRA -> BGRA2BGR, BGR -> copyTo),
    then per object: the rotated rect (4 lines; green when verdict Ok, red when Ng), a short
    axis from the anchor along `angle` (20 px, blue x-axis and red y-axis as the reference
    `drawAxes2Img`), the clearance zones of the pattern posed like ClearanceCondition does
    (yellow polylines) when the config has zones, and the region rectangle (white) when
    usingRoi. No text. `src/match/annotate.{h,cpp}`.
11. `result.status = Ok`, return.

## Implementation layout

- `src/match/image_matcher_impl.h`: `struct ImageMatcher::Impl` (group, logger, strategy
  `unique_ptr<IMatchStrategy>`, workspace `unique_ptr<IWorkspace>`, classifier, foreground
  extractor + `fg::ForegroundResult`, gray / crop / sub-crop `ScratchImage`s, candidate
  vectors, region list vector `{int contourIndex; int area; cv::Rect rect; std::vector<int>
  patterns}` with reserved capacity reused across calls, polygon scratch, `bool ready`).
- `src/match/image_matcher.cpp` (API + orchestration), `src/match/region_search.{h,cpp}`
  (steps 3-5), `src/match/result_sort.{h,cpp}`, `src/match/annotate.{h,cpp}`. Each file under
  400 lines, every function under 50 lines or justified.
- Allocation budget: steady state (same image size, same group) = zero allocations from
  library code; `MatchResult::objects` keeps capacity; `outcomes` vectors inside reused
  MatchedObjects keep capacity when the result object is reused (clear(), not new vector).
  OpenCV-internal allocations (findContours point vectors, warpAffine, Sobel) are tolerated
  and reported.
- `prepare()` is idempotent and cheap (compares a `ready` flag; `group()` non-const resets it).
- docs: update docs/getting-started.md "First match" to the real API (learn through the
  matcher, print `patternIndex` instead of a name) and drop the "planned" wording for the
  parts that now exist; docs/conditions.md: the SearchOptions table stays valid; add the
  early-stop semantics sentence.

## Tests (tests/unit/image_matcher_test.cpp, synthetic only)

Helpers: a 64x64 pattern (asymmetric dark shape on light, as edge_search_test), a scene
builder placing instances (same warpAffine recipe as edge_search_test: clockwise = +angle), a
group with one or two patterns learned through `ImageMatcher::learn()`.

1. `ReturnsEmptySourceOnEmptyImage`, `ReturnsNoPatternsOnEmptyGroup`,
   `ReturnsUnlearnedPatternBeforeLearn`, `ReturnsInvalidRoiWhenRoiOutsideImage`,
   `ReturnsNotReadyForUnsupportedCondition` (correlation group + ClearanceCondition ->
   prepare() fails and match() returns NotReady), `ReturnsNotReadyForCorrelationUntilM3`.
2. `FindsInstancesInImageFrame`: three instances at known poses, gray source: centers and
   angles (wrapped) within 1.5 px / 2*layerAngleStep(64x64) deg; `result.region` = full
   image; `stats.candidateRegions >= 3`, `rawCandidates >= 3`, `matches == 3`; status Ok;
   `found()` true.
3. `ColorSourcesGiveSameResultAsGray` (BGR and BGRA conversions).
4. `RoiLimitsSearchAndKeepsImageFrame`: two instances, roi around one -> 1 object whose
   center is in IMAGE coordinates (not crop) and `result.region` equals the clamped roi;
   roi partially outside the image is clamped, not rejected.
5. `TwoPatternsOverlapPassKeepsHigherScore`: pattern A and a near-identical pattern B
   (B = A with a small extra blob) on an instance of A: exactly one object survives the global
   overlap pass with the higher score.
6. `PerObjectConditionsProduceOutcomesAndCounts`: a ScoreRangeCondition(0.95) that rejects
   one of two instances (blur one instance): `okCount == 1`, `ngCount == 1`, outcomes on each
   object with name "ScoreRange", Ok object sorted first.
7. `StopAfterOkCountStopsBetweenRegions`: five well separated instances, stopAfterOkCount 2:
   `okCount >= 2` and `objects.size() < 5` (document that the exact count depends on region
   order), plus `stopAfterOkCount == 0` returns all 5.
8. `SetConditionsRunAfterSearch`: `MaxCountCondition(2)` on 4 instances -> 2 Ok, 2 Ng with the
   built-in reason; Ok ones sorted first by score.
9. `SortsByAngleWhenConfigured`: sortByAngle with sortTargetAngle 30 on instances at 0, 30,
   -60 -> order by wrapped distance; and the default order by score descending.
10. `ClearanceConditionRejectsCrowdedInstance`: pattern with a zone to its right; two
    instances, one with another blob inside its zone -> that one Ng "overlap", the other Ok.
11. `TranslatesObjectsAndAnchorsToImageFrame` with an off-center anchor in the pattern
    config and a roi: anchor = center + rotated anchor offset (compute with
    MatchedObject::transformAnchor) in image coordinates.
12. `AnnotatesWhenRequested`: `annotated` empty by default; with annotate true it is CV_8UC3
    of the source size and differs from the plain BGR source (countNonZero of the diff > 0);
    region rectangle drawn when usingRoi.
13. `ReusedResultKeepsCapacityAndStatsReset`: call match twice into the same MatchResult;
    second call: objects correct, stats reset (candidateRegions equals the first run's).
14. `SteadyStateMatchDoesNotGrowAllocations` (MSVC Debug `_CrtSetAllocHook`, same pattern as
    edge_search_test: runs 2 and 3 within max(60, 1%)); GTEST_SKIP elsewhere.
15. `GroupMutationRequiresPrepare`: after `group()` (non-const) `isReady()` is false; the
    next match() prepares automatically and succeeds.
16. `ThrowingConditionBecomesNg`: a condition whose evaluate throws -> Ng with the exception
    text as reason, status still Ok (Classifier behaviour, verified through the facade).
