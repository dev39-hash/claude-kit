# Brief M2 2.4b (+2.3b): edge search, EdgeStrategy, EdgeWorkspace, OpenMP over angles

Shared spec for the tester (RED) and the implementer (GREEN). Not tracked in git.
Rules of record: `.claude/rules/project.md` (ALL sections: naming, mutation policy, Performance
goals, Angle convention, Build slots), `.claude/rules/ecc/common/performance.md`.

## Goal

Port the reference `ImageMatcher::MatchEdge` (reference_source/matching/image_matcher.cpp
lines 508-795), `MatchEdgePattern_SIMD` (916-960), `GetBestRotationSize` (already ported as
`geom::bestRotationSize`), `GetRotatedROI` (1090-1105) and the surrounding glue into a stateless
`EdgeStrategy` (implements `IMatchStrategy`, src/match/match_strategy.h) with all scratch memory
in an `EdgeWorkspace`. Results must reproduce the reference bit-for-bit where the arithmetic is the
same, and within regression tolerance elsewhere (plan section 8). Goldens were produced by the
reference SIMD path (no greedy early-out): the score of a position is the plain mean over pattern
points of (Sx*Tx + Sy*Ty) / max(SMag*TMag, 1e-20), which is exactly `edge::edgeScore*`.

## API (shared contract; the tester codes against this)

```cpp
// src/edge/edge_workspace.h
namespace mtc {
namespace edge {
/// Owned, 32-byte aligned, continuous image storage that only grows. header(size, type)
/// returns a cv::Mat wrapping the storage (no ROI parent, so Sobel/warpAffine border
/// handling is the standalone-image behaviour). The header is valid until the next
/// reserve() that grows the storage.
class ScratchImage {
public:
    cv::Mat header(cv::Size size, int type);   // reserves if needed (allocation only on growth)
    std::size_t capacityBytes() const noexcept;
};

/// Per-thread scratch of one scoring pass.
struct ThreadScratch {
    ScratchImage rotated;            // CV_8UC1 rotated source / rotated ROI
    ScratchImage gx, gy, mag;        // CV_32FC1 gradient maps
    ScratchImage score;              // CV_32FC1 score map
    AlignedBuffer<float> sx, sy, smag;  // gather buffers, resizePadded(count), zero tail
    BlockMax blockMax;
    std::vector<MatchParams> found;  // per-angle candidates (coarse) / per-layer temp (fine)
};
}  // namespace edge

class EdgeWorkspace final : public IWorkspace {
public:
    std::vector<cv::Mat> srcPyramid;                 // cv::buildPyramid output (OpenCV-owned Mats; reused)
    std::vector<edge::ThreadScratch> threads;        // size = max OpenMP threads (1 without OpenMP)
    std::vector<double> angles;                      // coarse angle list
    std::vector<double> layerScores;                 // per-layer min score
    std::vector<MatchParams> coarse;                 // merged coarse candidates (sorted)
    std::vector<MatchParams> results;                // refined candidates
    std::vector<unsigned char> refined;              // per-coarse-candidate "produced a result" flag
    std::vector<cv::Point2f> polyScratch;            // for filterOverlap
    std::vector<int> deleted;                        // for filterOverlap
    int lastThreadCount = 0;
};
}  // namespace mtc

// src/edge/edge_search.h   (namespace mtc::edge)
/// Angle step of a layer: atan(2 / max(cols, rows)) * 180 / pi.
double layerAngleStep(cv::Size layerSize) noexcept;

/// Reference angle list: toleranceAngle < 1e-7 -> {0}; else 0, step, 2*step, ... while
/// a < tol + step; then -step, -2*step, ... while a > -tol - step. Appends into @p out (cleared).
void coarseAngles(double toleranceAngle, double step, std::vector<double>& out);

/// Reference GetRotatedROI, ported with geom::rotatePoint(p, c, -angle) in place of
/// ptRotatePt2f(p, c, angle*D2R). Output size = size + (6, 6); warpAffine with default
/// flags (INTER_LINEAR, BORDER_CONSTANT 0). @p out must already be a header of that size.
void rotatedRoi(const cv::Mat& src, cv::Size size, cv::Point2f ptLT, double angleDeg, cv::Mat& out);

/// Reference MatchEdgePattern_SIMD: Sobel(3) gx/gy + magnitude of @p rotatedSrc, then for
/// every window position gather + kernel; writes score >= minScore, else 0.
/// @return false when the result size would be <= 0 or the layer has no points.
bool scoreMap(const cv::Mat& rotatedSrc, const EdgeLayer& layer, double minScore,
              EdgeScoreFn kernel, ThreadScratch& s, cv::Mat& outScore);

/// Top-layer search over all angles (OpenMP over angles, per-thread scratch, merge in angle
/// order, then stable sort by score descending). Fills ws.coarse.
void coarseSearch(const EdgeLearnedPattern& pat, const SearchParams& p, EdgeScoreFn kernel,
                  EdgeWorkspace& ws);

/// Pyramid descent of one coarse candidate (reference fine loop). Returns true and fills
/// @p out when the candidate survives down to the stop layer.
bool refineCandidate(const EdgeLearnedPattern& pat, const SearchParams& p, EdgeScoreFn kernel,
                     const MatchParams& coarse, ThreadScratch& s, const EdgeWorkspace& ws,
                     MatchParams& out);

/// filterByScore, rotated rects at the stop-layer size, filterOverlap, stable sort, then
/// conversion to Candidate (layer-0 size). Appends to @p out.
void finalizeCandidates(const EdgeLearnedPattern& pat, const SearchParams& p, EdgeWorkspace& ws,
                        std::vector<Candidate>& out);

// src/edge/edge_strategy.h
namespace mtc {
class EdgeStrategy final : public IMatchStrategy {
public:
    MatchingType type() const noexcept override;            // EdgeBased
    std::unique_ptr<LearnedPattern> learn(const cv::Mat&, const IMatchTypeConfig&,
                                          const ForegroundConfig&, ManagerResult&) const override;
    std::unique_ptr<IWorkspace> createWorkspace() const override;   // EdgeWorkspace
    bool search(const cv::Mat& region, const LearnedPattern& pattern, const SearchParams& params,
                IWorkspace& workspace, std::vector<Candidate>& out) const override;
};
}
```

`learn`: `typeConfig.type()` must be EdgeBased (else status fails, nullptr); cast to
`EdgeMatchConfig` and delegate to `EdgeLearner`. `search`: `region` must be CV_8UC1 and
`pattern.type()` EdgeBased and `workspace` an EdgeWorkspace (else return false, no throw);
the reference size guards: return false when pattern cols > region cols AND rows > rows, or
pattern area > region area. `out` is appended to, never cleared by the strategy.

## Algorithm (port rules; the reference line numbers are the authority)

Conventions: `D2R`/`R2D` as `constexpr`; `kCandidateSlack = 5` (reference MATCH_CANDIDATE_NUM);
`kAngleEpsilon = 1e-7` (VISION_TOLERANCE); `kLayerScoreDecay = 0.7`; `kRoiPad = 3`.
Every reference `ptRotatePt2f(p, c, theta_rad)` becomes `geom::rotatePoint(p, c, -theta_deg)`
(proved: both give offset (dx cos t + dy sin t, -dx sin t + dy cos t) when t = theta).
`cv::getRotationMatrix2D(center, angle, 1.0)` calls stay literally as in the reference.

1. Pyramid: `cv::buildPyramid(region, ws.srcPyramid, pat.topLayer())`.
2. `step = layerAngleStep(top template size)`; `coarseAngles(p.toleranceAngle, step, ws.angles)`.
3. `layerScores[0] = p.minScore; layerScores[l] = layerScores[l-1] * 0.7`.
4. `calMaxByBlock = (srcTop.area() / tmplTop.area()) > 500 && p.maxPosNum > 10` (integer division).
5. Coarse, per angle a (OpenMP parallel for, schedule(dynamic), thread-local scratch):
   `sizeBest = geom::bestRotationSize(srcTop.size(), tmplTop.size(), a)`;
   `topCenter = ((W-1)/2.0f, (H-1)/2.0f)` (float); `fTx = (sizeBest.width-1)/2.0f - topCenter.x`,
   `fTy` likewise (float); `matR = getRotationMatrix2D(topCenter, a, 1.0)`; add fTx/fTy to the
   translation column; `warpAffine(srcTop, rotated, matR, sizeBest, INTER_LINEAR, BORDER_CONSTANT,
   Scalar(pat.borderColor))`; `scoreMap(...)`, skip angle on false.
   If calMaxByBlock: `blockMax.build(score, tmplTop.size())`, `maxValueLoc`, skip angle when
   max < layerScores[top]; push `MatchParams(Point2f(ptMax.x - fTx, ptMax.y - fTy), max, a)`
   (float subtraction, then widened); then up to `p.maxPosNum + kCandidateSlack - 1` times:
   `nextMaxLoc(score, ptMax, tmplTop.size(), p.maxOverlap, value, blockMax)`, break when value
   < layerScores[top], else push. Else the same with `minMaxLoc` and the non-block `nextMaxLoc`.
   Merge: concatenate per-angle lists in angle-index order, then `std::stable_sort` by score
   descending (reference used std::sort; stable is deterministic and tie-order is irrelevant for
   goldens with distinct scores).
6. Fine, per coarse candidate (OpenMP parallel for over candidates, result slot per index,
   merged in index order): `stopLayer = p.stopAtLayer1 ? 1 : 0`;
   `ptLT = rotatePoint(c.point, topCenter, +c.matchAngle)` (reference: ptRotatePt2f with
   -angle*D2R). If `top <= stopLayer`: point = ptLT * (top == 0 ? 1 : 2), result = candidate.
   Else for layer = top-1 .. stopLayer:
   `ls = layerAngleStep(tmpl[layer].size())`; angles = {0} if tolerance < eps else
   {a - ls, a, a + ls}; `srcCenter = ((cols-1)/2.0f, (rows-1)/2.0f)` of srcPyramid[layer];
   for each angle j: `rotatedRoi(srcPyramid[layer], tmpl[layer].size(), ptLT * 2, angle_j, roi)`;
   `scoreMap(roi, ...)` (if it returns false treat the score as 0 at (0,0), on border);
   `minMaxLoc` -> ptMax, val; `posOnBorder` when ptMax on any edge of the score map; when not on
   border copy the 3x3 neighbourhood into `vecResult[x+1][y+1] = score(ptMax + (x, y))`.
   Best j = argmax (first wins on ties, strict >). If best score < layerScores[layer]: drop the
   candidate (return false). Sub-pixel when `p.subPixel && layer == 0 && !best.posOnBorder &&
   bestIdx == 1` (reference: != 0 && != 2): fill `SubPixelSamples` as documented in
   `src/match/subpixel.h` (transpose; each angle layer at its own argmax), `angleStep = ls`,
   `refineSubPixel`; when `ok`: point = ptMax + (dx, dy), angle += dAngle, mark subPixel. If not
   ok keep the integer pose (reference always applied the fit; the new validity gate is a
   documented deviation, tolerance covers it).
   `newAngle` = best angle; `ptPad = rotatePoint(ptLT * 2, srcCenter, -newAngle) - (3, 3)`;
   `pt = best.point + ptPad`; `pt = rotatePoint(pt, srcCenter, +newAngle)`.
   If layer == stopLayer: point = pt * (stopLayer == 0 ? 1 : 2), angle = newAngle, score = best
   score -> result. Else: candidate.matchAngle = newAngle, ptLT = pt, continue.
   Keep the float/double mix of the reference (Point2f for ptLT/pt/ptPad, double for angles).
7. Finalize: `match::filterByScore(results, p.minScore)`; `dstW/H = tmpl[stopLayer] size *
   (stopLayer == 0 ? 1 : 2)`; `rectR = RotatedRect(LT, RT, RB)` with
   `RT = LT + dstW * (cos a, sin a)`, `LB = LT + dstH * (-sin a, cos a)`, `RB = RT + (LB - LT)`
   (this is the reference formula with dRA = -a rewritten; float casts as in the reference);
   `match::filterOverlap(results, p.maxOverlap, ws.polyScratch, &ws.deleted)`; stable sort by
   score descending. `p.maxMatches` is NOT applied here (the facade applies it after the
   global overlap pass); document that in the header.
   Candidate: `W, H = tmpl[0] size`; `center = LT + rotatePoint((W/2, H/2) offset, origin 0,
   a)` i.e. `center = LT + (cos a * W/2 - sin a * H/2, sin a * W/2 + cos a * H/2)`;
   `rect = RotatedRect(center, Size2f(W, H), a)` (its points()[1] == LT); `angle = a`
   (unwrapped; MatchedObject wraps); `score`; `subPixel`; `patternIndex = -1`.
   `if (p.stats) p.stats->rawCandidates += coarse count` (only counters; timing is the facade's).
   Logger: at most one summary line per search, only when `p.logger` is set.

## Allocation budget (user priority; reviewer checks it)

- Steady state (second call with the same region size and pattern): ZERO allocations from
  library code. All `cv::Mat` outputs are headers from `ScratchImage` sized by capacity;
  `srcPyramid` Mats are reused by `buildPyramid` (same size -> `create` is a no-op);
  vectors keep capacity (`clear()`); `AlignedBuffer::resizePadded` only grows.
- Gather buffers are sized once per search to the largest layer count; `BlockMax::build`
  reuses capacity (documented in block_max.h).
- `threads.resize(omp_get_max_threads())` happens on the first search and when the thread
  count grows. Allocations inside OpenCV (`warpAffine`, `Sobel`, `magnitude`, `buildPyramid`
  internals) are outside our control; report their count (tester measures with
  `_CrtSetAllocHook` on MSVC Debug).
- Never `clone()`; never create a temporary `cv::Mat` in the per-angle / per-candidate /
  per-position loops; `selectEdgeScore()` once per search.

## OpenMP (2.3b)

`#pragma omp parallel for schedule(dynamic)` over coarse angles and over coarse candidates in
the fine stage, guarded by `#ifdef MTC_USE_OPENMP` (`_OPENMP`), each thread using
`ws.threads[omp_get_thread_num()]`. Results go to per-index slots and are merged in index order
so the output is byte-identical for any thread count. `omp_get_max_threads()` is 1 when
OpenMP is off. No shared mutable state inside the parallel regions except the per-index slots.

## Tests (tester; synthetic, no fixtures)

asymmetric dark shape on a light background (e.g. an "L" of two filled rectangles plus a filled

position: 1.5 px without sub-pixel, 1.0 px with.
