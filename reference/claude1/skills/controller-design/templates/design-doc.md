## 7. Tests and invariants

Invariants (checked after every step): `readiness().ok()` iff the ready output; fault latched
iff the fault output and code; each chosen block's invariants (the `controller-kernel` skill,
blocks table); the controller's own. The checker lives in the controller's test file (Harness).

Completeness sweep: prepared states (name each) x one sample per event kind (list); a check that
the sample count equals `std::variant_size_v<Event>`.

Stale probes: one per request kind (job, attempt, write) and one per timer key.

## 8. Scenarios

Index of scenario files (`scenario.md` instances) with their test names. Minimum five:
normal run; role lost mid-job; master lost; acknowledge while a role is still down; stop
during start-up.
