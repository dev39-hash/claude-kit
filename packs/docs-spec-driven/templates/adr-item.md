# Architecture decisions

Project-wide decisions, numbered in the order they were made. Cite an item as `ADR Dn`
(with the prefix) from code comments, specs and other docs. Items are never renumbered,
reordered or rewritten: a correction is an amendment paragraph, a replacement is a new
item that names the old one. Plan-local decisions stay in their plan under
`docs/history/plan/`.
